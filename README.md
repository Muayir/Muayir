# معاير | Muayir

أداة ويندوز بواجهة نيون: تثبيت أهم البرامج بضغطة وحدة، وتويكات آمنة تقدر ترجعها في أي وقت.

## التشغيل السريع (من النت)

افتح **PowerShell** واكتب:

```powershell
irm "https://raw.githubusercontent.com/Muayir/Muayir/main/Muayir.ps1" | iex
```

> غيّر `Muayir` لاسم حسابك في GitHub. لو ما فتحت PowerShell كـ Administrator، الأداة تطلب الصلاحية بنفسها.

## التشغيل من الجهاز

اضغط دبل كليك على **Run-Muayir.bat**، ووافق على طلب صلاحية المسؤول.

## المميزات

- **Install**: أكثر من 80 برنامج مع اللوقو حقها، والتثبيت يصير عن طريق winget من المصادر الرسمية.
- **Tweaks**: تويكات للخصوصية والقيمنق وشكل الويندوز.
- **Undo**: كل تعديل ينحفظ قبل ما يتطبق، فتقدر ترجع كل شي مثل ما كان.
- **Restore Point**: تنسوي نقطة استعادة تلقائياً قبل التويكات.

## إضافة برنامج

1. اعرف الـ ID حقه بالأمر: `winget search اسم_البرنامج`
2. أضف سطر في قسم `$Apps` داخل الملف، بالشكل هذا:

```powershell
@('الاسم','Winget.ID','الموقع.com'),
```

## الملفات

| الملف | وش هو |
|---|---|
| `Muayir.ps1` | الأداة نفسها |
| `Run-Muayir.bat` | تشغيل بدبل كليك |
| `%LOCALAPPDATA%\Muayir` | النسخة الاحتياطية للتويكات والـ log |
